# Triageetiketter

Använd följande kanoniska tillståndsetiketter:

- `needs-triage` — ännu inte bedömd eller avgränsad.
- `needs-info` — kräver information eller ett beslut innan arbetet kan börja.
- `ready-for-agent` — tillräckligt tydlig och säker för självständigt arbete.
- `ready-for-human` — kräver mänsklig designbedömning, prototypgodkännande
  eller annan manuell insats.
- `wontfix` — medvetet avvisad, med motivering i issuet.

En ticket ska ha högst en av dessa tillståndsetiketter åt gången. Övriga
produkt-, område- och prioritetslabels kan komplettera tillståndet.
