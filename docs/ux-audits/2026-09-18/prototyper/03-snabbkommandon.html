Vad som prövas

Varje handling på bordet går i dag genom hjulet: ett klick eller ett håll, sedan en eke. För det man gör om och om igen — vända, dra, blanda — är det ett steg för mycket. Klicka på ett kort för att se hjulet, och Cmd-klicka (Ctrl på Windows och Linux) för att vända direkt.

Förslag på kommandon, att godkänna eller stryka:

TangentGörVarför just den

Varje kommando finns också som en väg utan modifierare, för den som inte kan hålla två tangenter. Allt går genom samma intents som hjulet — inga nya verb.
