# PROTOTYP — player-vyn

Fråga: hur ser och används handen i telefonen?

Kör: `pnpm proto` → http://localhost:5173/prototype/player?variant=A (mobilviewport)

- **A — Remsan.** K4 som beslutat: stora kort i remsa, tryck = titta, dra upp = ark med zongenvägar, håll = flerval.
- **B — Kortlek i handen.** Ett kort i fullskärm, svep i sidled, svep upp för att spela, miniatyrrad.
- **C — Bräde + hand.** Minibord med zoner som brickor överst, handen i rutnät nederst, tryck kort → tryck bricka.

## Svar (2026-09-06)

**A — Remsan.**
Stora kort i horisontell remsa nederst; tryck = inspektera i fullstorlek; dra upp = ark med zongenvägar; håll = flerval.
Mitten är en kollapsad bordsöversikt (zoner med antal) och senaste-flödet — C4:s "fäll ut bordet" i minsta format.
Prototypen ligger kvar som referens tills den riktiga vyn är byggd, och tas sedan bort.
